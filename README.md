# physics_drop — покадровый анализ падения мяча

Разбор видео `drop.mp4` (720×1280, 30 к/с, 3,63 с, 109 кадров): мяч отпускают у верхнего края
бумажной шкалы, он падает вдоль неё, бьётся о мат и отскакивает. Всё измерено по кадрам:
координаты мяча, скорости, ускорение и коэффициент восстановления.

**Живая версия:** <https://data.nayanovaacademy.ru/> (интерактивный плеер, графики, таблица
по кадрам и раздел «Школьная физика»).

## Результаты

| Величина | Значение | Комментарий |
|---|---|---|
| Высота падения (центр мяча) | 1,82 ± 0,09 м | отпущен без начальной скорости; ±5 % — систематическая погрешность масштаба |
| Время падения | 0,63 с | 19 кадров при 30 к/с |
| Скорость у мата | 5,9 ± 0,3 м/с | по подгонке параболы |
| Высота отскока | 75 см над матом | 42 % от высоты падения |
| Коэффициент восстановления | e ≈ 0,63 по скоростям, 0,645 по высотам | разница — оценка неопределённости |
| Ускорение свободного падения | 9,3 и 9,7 м/с²; итог 9,5 ± 0,5 | два независимых участка |
| Второй удар | через 0,76 с после первого | 22,9 кадра |
| Потеря кинетической энергии | ≈60 % | 1 − e² |

## Как воспроизвести

```bash
# зависимости
python -m pip install -r requirements.txt

# 1. измерения и графики (кадры извлекаются автоматически через ffmpeg)
python analysis/final_analysis.py
python analysis/meta.py            # meta.json для маркера

# 2. отчёты
python analysis/make_report.py     # report.md
python analysis/make_html.py       # report.html (автономный)
python analysis/make_school_html.py # school_physics.html из school_physics.md
python analysis/selftest.py        # быстрая проверка

# 3. (необязательно) версия для сервера
python analysis/split_for_server.py  # analysis/deploy/
```

Нужен `ffmpeg` в `PATH`. Если кадры уже лежат в `analysis/frames/`, шаг извлечения
пропускается. Все скрипты работают из своего каталога и не используют абсолютных путей
вроде `C:\projects\...`.

## Как считали

1. **Детекция мяча** — три способа: по цвету (красный «поясок» мяча), по разности с фоном
   на кадрах, где мяч смазан движением, и по модели в момент удара (кадры 50–52 полностью
   смазаны).
2. **Калибровка** — метки 10…160 см на бумажной шкале считаны с кадров и описаны квадратичной
   зависимостью `y(см) = 158,6 + 6,503·Y − 0,004193·Y²` (СКО 2,5 px, максимум ≈5 px).
   Шкала не плоская, поэтому масштаб меняется от 6,50 до 5,16 px/см; для мяча взят
   постоянный масштаб 5,70 px/см.
3. **Подгонка** — два участка полёта (падение и отскок) аппроксимированы параболами, точка
   удара — их пересечение. Ускорение 5,91 и 6,13 px/кадр² → g = 9,3 и 9,7 м/с².

Точность: координаты ±0,5 см на резких кадрах и ±1…1,5 см на смазанных; скорости ±0,3 м/с;
g ±0,5 м/с². Основная погрешность — масштаб и перспектива (мяч летит не в плоскости шкалы),
она разобрана в отчёте, §9.

## Школьная физика

В `report.html` есть отдельный раздел «Школьная физика» с картой тем 7–11 классов,
восемью интерактивными моделями и интерактивом про импульс в §4:

* свободное падение и g на планетах;
* отскок, коэффициент восстановления и геометрическая прогрессия высот;
* импульс, средняя сила и давление при ударе;
* энергия Ep/Ek по кадрам и оценка нагрева;
* сопротивление воздуха и ограничение на массу мяча;
* размытие и частота кадров;
* параллакс и ошибка масштаба;
* подгонка параболы (МНК) вручную;
* звук удара: waveform и интервал между хлопками.

Подробный конспект с планами уроков, вопросами и типичными ошибками — в
[`analysis/school_physics.html`](analysis/school_physics.html) (веб-версия) и
[`analysis/school_physics.md`](analysis/school_physics.md) (Markdown).
