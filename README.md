# physics_drop — покадровый анализ падения мяча

Разбор видео `drop.mp4` (720×1280, 30 к/с, 3,63 с, 109 кадров): мяч отпускают у верхнего края
бумажной шкалы, он падает вдоль неё, бьётся о мат и отскакивает. Всё измерено по кадрам:
координаты мяча, скорости, ускорение и коэффициент восстановления.

**Живая версия:** <https://data.nayanovaacademy.ru/> (интерактивный плеер, графики, таблица по кадрам)

## Результаты

| Величина | Значение |
|---|---|
| Высота падения | 1,82 м (отпущен без начальной скорости) |
| Время падения | 0,63 с |
| Скорость у мата | 5,9 м/с |
| Высота отскока | 75 см над матом |
| Коэффициент восстановления | e ≈ 0,63 (потеря энергии ≈ 60 %) |
| Ускорение свободного падения | 9,3 м/с² (падение) и 9,7 м/с² (отскок), итог 9,5 ± 0,5 |
| Второй удар | через 0,76 с после первого |

Подробности — в [`analysis/report.md`](analysis/report.md) и в интерактивном `analysis/report.html`.

## Как воспроизвести

```bash
# 1. кадры (нужен ffmpeg)
ffmpeg -i drop.mp4 -vsync 0 analysis/frames/f_%03d.png

# 2. измерения и графики
python analysis/meta.py            # meta.json
python analysis/final_analysis.py  # frames.csv + все PNG

# 3. отчёты
python analysis/make_report.py     # report.md
python analysis/make_html.py       # report.html (автономный)
python analysis/split_for_server.py  # analysis/deploy/ для выкладки
```

Зависимости: `numpy`, `pillow`, `matplotlib`, `imageio-ffmpeg`.

## Как считали

1. **Детекция мяча** — три способа: по цвету (красный «поясок» мяча), по разности с фоном
   на кадрах, где мяч смазан движением, и по модели в момент удара (кадры 50–52 полностью смазаны).
2. **Калибровка** — метки 10…160 см на бумажной шкале считаны с кадров и описаны квадратичной
   зависимостью `y(см) = 158,6 + 6,503·Y − 0,004193·Y²` (СКО 2,5 px). Шкала не плоская, поэтому
   масштаб меняется от 6,53 до 5,16 px/см; для мяча взят постоянный масштаб 5,70 px/см.
3. **Подгонка** — два участка полёта (падение и отскок) аппроксимированы параболами, точка удара —
   их пересечение. Ускорение 5,91 и 6,13 px/кадр² → g = 9,3 и 9,7 м/с².

Точность: координаты ±0,5 см, скорости ±0,1 м/с, g ±0,5 м/с² (основная погрешность — масштаб шкалы,
она разобрана в отчёте, §7).
